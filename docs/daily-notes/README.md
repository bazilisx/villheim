# Daily notes

Dated, append-only log of every working session. `docs/SESSION_HISTORY.md` holds only current facts and links here
for the detail.

## Rules

- One file per calendar day (Mountain Time), `YYYY-MM/YYYY-MM-DD.md`. Create the month folder when needed.
- Always start a new day from `DAILY_NOTE_TEMPLATE.md`.
- If today's file exists, append `## Session N` and add a line to `## Index`. Never overwrite earlier sessions.
- Write what happened: changes, tests, errors, fixes, open items. This is a log, not a status doc.
- Objective records only: no descriptions of anyone's mood or tone.
