# Feature list

Every Villheim feature in one list: what is built, in progress, planned or proposed, and ideas seen in other mods and games. It is in `docs/features/features.csv`, one row per feature, grouped by category, with its sources, a rough effort (S an evening, M a session or two, L several sessions) and notes on rules or decisions it touches.

Status: **Built and tested** (seen working in game), **Built, not tested in game** (code is in, never run in game), **In progress** (being worked on or known still broken), **Planned** (on the roadmap or the world life plan), **Proposed** (a written proposal, not on the roadmap), **Seen in another mod** (seen in another mod or game, no Villheim plan yet).

`citybuilder.csv` holds the ValheimCityBuilder rows (see `docs/CITYBUILDER_STUDY.md`). `checklist.csv` joins both lists, leaving out CityBuilder rows that Villheim already has, 730 rows in all. Tyler's Yes, No or Later for each row goes in the Features tab of the review sheet.
