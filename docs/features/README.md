# Feature list

`box.csv` is the list Tyler reviews: 166 player-facing features, the kind listed on the back of a game box, grouped by
category. It is the Features tab of the review sheet, where each row gets Yes, No or Later in the Integrate? column.
Rows already in the mod (built, tested or not, and the two in progress) are marked Included there and hidden by the
tab's filter.

Status: **Built and tested** (seen working in game), **Built and not tested yet** (code is in, not yet run in game),
**In progress**, **Planned** (on the roadmap), **Idea** (proposed, or seen in another mod or game).

The Detailed rows column points at the long lists the box list was made from: `features.csv` (588 rows from
Villheim's docs, code and other mods), `citybuilder.csv` (187 ValheimCityBuilder rows) and `checklist.csv` (both
joined). Those keep the small decisions and dev tools that the box list leaves out.
