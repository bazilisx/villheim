# Villheim cultures: names, looks, feasts and building sets for each people a village can belong to.
# Read by Village/Cultures.cs. Built into the logic DLL, so a change reloads with it.
#
# Villages are echoes of the old world the heroes came from: the Norse and the peoples they traded with, settled
# among or served beside. Which cultures a biome's villages may have is the setting CultureMap (config section
# "5c - Cultures"). Names come from real naming traditions of each people, written in plain letters.
#
# [key] starts a culture. Fields:
#   base = key            copy every field of that culture first (a "+" field adds to the copied list)
#   name                  shown in commands
#   people                group tag for dialogue lines (people:norse, people:celtic...)
#   leader                title of the village's first settler (the Norse say Jarl)
#   male, female          given names, separated by commas
#   surname               none, norse (father's name + son or daughter), mac (mac or ingen + father), ibn (ibn or
#                         bint + father), slavic (father's name + ich or na), de (de + a place from "seats"),
#                         list (a family name from "families", written male/female)
#   surnamechance         share of villagers who use the surname (default 1)
#   seats, families       lists for the "de" and "list" styles
#   places.start/.end     parts for village and home place names
#   festivals             the four seasonal feasts, spring | summer | autumn | winter
#   skin                  range on the game's skin slider, 0 palest, 1 darkest (the game gives no paler than 0.25 here)
#   hairshade             hair brightness range, 0.1 near black to 1 full colour
#   hairred               0 fair, 1 red
#   beard                 share of men with a beard
#   hair, beardstyle      words in the game's style names that are given more often, word:weight
#   chest, legs, helmet,  extra vanilla clothes for this culture, Prefab@fromTier:weight; "f:" women only, "m:" men
#   cape                  only; "*" at the end takes any item whose name starts so (ArmorTunic*). Missing items are
#                         skipped, so a missing prefab never leaves a villager bare.
#   designs.hub/.house/.workshop/.farm/.storage   design tiers tried before the biome's own (same form as Culture.cs)
