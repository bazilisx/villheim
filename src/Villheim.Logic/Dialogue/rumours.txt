# Villheim: what villagers know of the land round them. Same format as lines.txt. Every line here is about a real
# place the village has found (Village/Knowledge.cs, Village/Rumours.cs); nothing in it may name a place or a creature
# that the tags don't vouch for.
#
# Tags: rumour, rumour:saw (he saw it himself), rumour:heard (someone told him in a chat), rumour:common (the whole
# village has heard by now), rumour:<kind>, rumour:<kind>:<key>, rumour:near, rumour:far, rumour:spotted (seen from a
# way off only), rumour:new (he found it today), rumour:felled (a boss that is down), rumour:when:day/night/any,
# rumour:terrain:sea/river/mountain/ridge/swamp/forest/hill/high/down/shore/flat. Chat: tell:rumour (he is passing it on).
# Kinds and keys: boss eikthyr elder bonemass moder yagluth queen fader; dungeon burial sunkencrypt trollcave frostcave
# infestedmine; trader haldor hildir bogwitch; runestone; landmark stones tarpit tower giant henge dolmen wreck well
# cairn drakenest greydwarfcamp; ruin; fuling; dvergr; ore copper tin silver obsidian iron flametal; nest greydwarfnest
# draugrpile bonepile; forage raspberries blueberries cloudberries beehive; game boar deer neck hare lox; foe (creatures
# that fight); biome meadows blackforest swamp mountain plains ocean mistlands ashlands deepnorth.
#
# Fill-ins: {thing} (what it is, "a troll cave"), {thingshort} ("the troll cave"), {where} ("over the ridge to the
# north, a good walk"), {direction} ("to the north"), {terrain} ("over the ridge", or "out" on the flat), {distance}
# ("a good walk"), {witness} (who found it), {rteller} (who told him), {daysago}, {when} ("by day", "at night").
#
# Firsthand lines say "I". Heard lines name {rteller} or {witness}. Common lines say "they say" or name {witness}.
# Boss lines say what the place is and no more.

# ================================================================== bosses
